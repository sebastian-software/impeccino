# Distill

Remove unnecessary complexity from the requested interface.

Trace the primary job and distinguish duplicate presentation from necessary
capability. Simplify the owning structure, content, or interaction instead of
merely hiding controls. Preserve semantic color and type roles, reachable
functions, factual content, and important states. Explain removed complexity
and verify the complete task path, recovery, and responsive behavior.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
