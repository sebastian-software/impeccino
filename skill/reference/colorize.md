# Colorize

Improve color’s role in the requested surface.

Read incumbent tokens, brand constraints, themes, and semantic state colors.
Identify the requested hierarchy or meaning before selecting a palette change.
Use suitable color knowledge; catalog seeds are optional candidates, not laws.
Preserve confirmed identity and established roles unless replacement is in scope.
Verify actual text, controls, focus, states, media, and all affected themes;
one seed color or a contrast check alone cannot establish overall quality.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
