# Overdrive

Implement an ambitious visual or interaction technique that serves the requested outcome.

Read the brief, incumbent identity, platform support, and available runtime.
Resolve an actually open choice when needed; a specified technique does not
require another proposal or approval ceremony. Use suitable specialist knowledge
for the chosen effect. Keep the semantic core, controls, content, and fallback
usable when the enhancement is unavailable. Verify the rendered technique,
interaction, interruption, reduced motion, and affected performance.
Use SKILL.md’s evidence and stop criteria; the host controls the inspection
budget. Do not continue decorative iteration after the outcome and checks pass.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
