# Delight

Add a useful moment of personality to the requested experience.

Find the real user moment and its emotional or functional job. Use the product’s
language and incumbent system rather than generic whimsy. Preserve recovery,
clarity, user control, accessibility, and performance; an error or sensitive
operation needs truthful help before ornament. Verify the moment in its actual
flow, including repetition, dismissal, motion preferences, and failure states.
Explain what changed without claiming an unmeasured emotional outcome.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
