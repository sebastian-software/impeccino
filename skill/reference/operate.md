# Operate

Resolve design work for a task-oriented or reading surface.

Use the surface’s mode and actual user path to select suitable knowledge.
Operate prioritizes completing the task, relevant data and states, consistency,
and supported platform affordances. Read prioritizes the reader’s question,
source material, comprehension path, and wayfinding. Personality can serve
either mode; there is no mandatory font count, timing, palette, or measure.
Preserve the incumbent system during refinement. Inspect real content, relevant
states, focus, reading/source order, density, and the primary action. Record mode
only in the relevant SURFACES.md section when persistence is in scope.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
