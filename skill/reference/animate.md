# Animate

Add or improve motion for the requested interaction or reading path.

Establish the motion’s actual job and relevant states before choosing a technique.
Use suitable motion and runtime knowledge, the incumbent identity, and supported
platform behavior. Preserve visible content, usable controls, and truthful state.

## Accessibility and control

Verify a `prefers-reduced-motion` path with an intentional alternative: reduce
spatial movement while retaining legible feedback, not disabling all motion.
Respect existing autoplay and sound preferences. Check interruption, repeated
input, hidden/offscreen behavior, and cleanup for the implemented effect.

## Verify

Exercise the actual trigger, completion, cancellation, and reduced-motion path.
Inspect relevant viewports and measure expensive effects when warranted.
Report unavailable input or performance coverage instead of certifying it.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
