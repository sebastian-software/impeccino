# Quieter

Reduce the requested surface’s visual or interaction intensity.

Identify what interrupts its reading or task path. Reduce competing emphasis,
ornamental motion, or redundant chrome while retaining meaningful state,
feedback, capability, and identity. Select suitable knowledge for this surface’s
mode. Verify that the primary action remains discoverable and that quieter
presentation has not erased boundaries, contrast, or useful information.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
