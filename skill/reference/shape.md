# Shape

Discover what should be made and how it should work. Return a useful brief;
shape does not write code or persist a direction contract unless requested.

## Discover the task

Read the requested target and existing context before asking. Establish the
surface's audience and job, success, real content and evidence, important states
and ranges, interaction, platform constraints, and what remains untouched.
Reuse settled facts. Select suitable planning knowledge available to the host.

Use one focused discovery round when material gaps remain. Ask through the
host's structured question tool when available; keep questions concrete and
related. A precise prompt can proceed directly. Additional rounds serve new
material gaps, never compulsory confirmation. Follow the host's autonomy and
question policy; label assumptions and unresolved facts honestly.

## Resolve direction

Use [new-work.md](new-work.md) when a new surface or identity needs direction.
An established world remains authority for refinement. A concept roll and
alternative directions are optional tools for an actual choice, not gates.
Return before implementation or persistence.

## Return the brief

Use the smallest form that lets a builder act: audience and outcome; target and
untouched boundaries; selected direction and interaction; relevant content,
states, and constraints; open decisions and required evidence. A settled task
may need only a few bullets. Do not repeat the conversation or invent claims.
Offer a targeted question only when an unresolved decision needs an answer.
