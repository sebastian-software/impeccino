Improve the requested interface copy without changing product truth.

Read the actual action, state, audience, and existing terminology. Rewrite
labels, instructions, errors, and recovery for their real function. Preserve
supported claims, legal meaning, behavior, and localization contracts. Ask only
about facts that cannot be established; never invent outcomes or promises.
Verify labels against their destinations and error text against actual recovery,
including accessible names, long or translated text, and important states.

Apply [craft-floor.md](craft-floor.md) before implementation. Use the resolved
target and existing answers; ask only about material gaps through the host's
structured question tool when available. These contracts follow
the host’s authorization, questions, delegation, and verification budget.
