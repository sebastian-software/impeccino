# Contributing

Start with the [Developer Guide](docs/DEVELOP.md) for the project layout, style, and validation commands.

Open an issue before a larger change; small fixes can go straight to a pull request. Run the checks that cover your change and list them in the pull request.

Do not bump skill or engine versions in a feature change. Maintainers handle version bumps when they prepare a release. If AI assisted you, disclose that in commit and pull request descriptions.
